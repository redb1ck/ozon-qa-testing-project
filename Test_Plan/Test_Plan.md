
 Test Plan — Marketplace Web Application
 1. Общая информация

Название проекта:
Ozon QA Testing Project

Тип тестирования:
Ручное тестирование веб-приложения маркетплейса

Цель тестирования:
Проверка основных пользовательских сценариев и выявление дефектов.

 2. Область тестирования

В рамках проекта проверяются:

- поиск товаров;
- фильтрация;
- карточка товара;
- корзина;
- оформление заказа;
- личный кабинет.

 3. Виды тестирования

- Smoke testing
- Functional testing
- Regression testing
- UI testing
- Exploratory testing
