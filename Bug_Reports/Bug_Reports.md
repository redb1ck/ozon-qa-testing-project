Bug Reports — Marketplace Web Application


Проект:
Ozon QA Testing Project


Описание:

В рамках учебного проекта была выполнена практика оформления баг-репортов на основе анализа пользовательских сценариев веб-приложения маркетплейса.

Дефекты, представленные в данном разделе, являются учебными примерами, созданными для демонстрации навыков QA-инженера.

Цель проекта:

Развитие навыков поиска, анализа и документирования дефектов в формате, приближенном к реальному рабочему процессу команды тестирования.

В процессе подготовки баг-репортов были использованы следующие элементы:

Примечание:

Представленные ниже дефекты являются учебными симуляциями, созданными для практики оформления QA-документации.

Они не являются официальными сообщениями о дефектах реального продукта.






BUG-001


Название:
Не обновляется итоговая стоимость после изменения количества товара в корзине


Тип:
Учебная симуляция дефекта


Раздел:
Корзина


Окружение:

Браузер:
Яндекс Браузер

Операционная система:
Windows 11


Предусловия:

Пользователь авторизован.
В корзине находится добавленный товар.


Шаги воспроизведения:

1. Открыть карточку товара.
2. Добавить товар в корзину.
3. Перейти в корзину.
4. Изменить количество товара.


Ожидаемый результат:

Итоговая стоимость автоматически пересчитывается после изменения количества товара.


Фактический результат:

Итоговая стоимость отображается некорректно после изменения количества товара.


Severity:
Major


Priority:
High


Статус:
Открыт


Связанный тест-кейс:
TC-CART-001






BUG-002


Название:
Фильтр цены не учитывает выбранный диапазон


Тип:
Учебная симуляция дефекта


Раздел:
Каталог товаров


Окружение:

Браузер:
Яндекс Браузер

Операционная система:
Windows 11


Предусловия:

Открыта страница категории товаров.


Шаги воспроизведения:

1. Открыть категорию товаров.
2. Установить диапазон цены.

Фактический результат:

В результатах поиска остаются товары, которые не соответствуют установленному диапазону.


Severity:
Major


Priority:
Medium


Статус:
Открыт


Связанный тест-кейс:
TC-SEARCH-001






BUG-003


Название:
Кнопка добавления товара в корзину не изменяет состояние после нажатия


Тип:
Учебная симуляция дефекта


Раздел:
Карточка товара


Окружение:

Браузер:
Яндекс Браузер

Операционная система:
Windows 11


Предусловия:

Открыта карточка товара.


Шаги воспроизведения:

Фактический результат:

Low

BUG-004


Название:
Отсутствует сообщение об ошибке при незаполненном обязательном поле


Тип:
Учебная симуляция дефекта


Раздел:
Оформление заказа


Окружение:

Браузер:
Яндекс Браузер

Операционная система:
Windows 11


Предусловия:

Пользователь находится на странице оформления заказа.


Шаги воспроизведения:

1. Перейти к оформлению заказа.
2. Оставить обязательное поле пустым.
3. Нажать кнопку продолжения.


Ожидаемый результат:

Система показывает сообщение о необходимости заполнить обязательное поле.


Фактический результат:

Пользователь может продолжить оформление без заполнения обязательного поля.


Severity:
Critical


Priority:
High


Статус:
Открыт


Связанный тест-кейс:
TC-CHECKOUT-001



BUG-005


Название:
Некорректное отображение информации о скидке в карточке товара


Тип:
Учебная симуляция дефекта


Раздел:
Карточка товара


Окружение:

Браузер:
Яндекс Браузер

Операционная система:
Windows 11


Предусловия:

Открыта карточка товара со скидкой.


Шаги воспроизведения:

1. Открыть товар со скидкой.
2. Сравнить старую и новую цену.
3. Проверить отображаемый процент скидки.


Ожидаемый результат:

Процент скидки соответствует разнице между старой и новой ценой.


Фактический результат:

Процент скидки отображается некорректно.


Severity:
Minor


Priority:
Medium
