Test Cases — Marketplace Web Application


Общая информация

Проект:
Ozon QA Testing Project

Тип тестирования:
Manual Testing

Цель:
Проверка основных пользовательских сценариев веб-приложения маркетплейса.



Раздел: Авторизация


TC-AUTH-001

Название:
Успешная авторизация пользователя

Предусловия:
Пользователь находится на странице входа.

Шаги:
1. Открыть страницу авторизации.
2. Ввести корректный номер телефона.
3. Ввести код подтверждения.
4. Нажать кнопку входа.

Ожидаемый результат:
Пользователь успешно входит в аккаунт и открывается личный кабинет.

Фактический результат:
Авторизация выполнена успешно.

Статус:
Pass



TC-AUTH-002

Название:
Проверка авторизации с некорректными данными

Предусловия:
Открыта форма входа.

Шаги:
1. Ввести некорректный номер телефона.
2. Нажать кнопку продолжения.

Ожидаемый результат:
Отображается сообщение об ошибке.

Фактический результат:
Сообщение об ошибке отображается.

Статус:
Pass



Раздел: Поиск товаров


TC-SEARCH-001

Название:
Поиск товара по ключевому слову

Предусловия:
Открыта главная страница.

Шаги:
1. Ввести название товара в поисковую строку.
2. Нажать кнопку поиска.

Ожидаемый результат:
Отображается список товаров, соответствующих запросу.

Фактический результат:
Список товаров отображается.

Статус:
Pass



Раздел: Карточка товара


TC-PRODUCT-001

Название:
Проверка отображения карточки товара

Шаги:
1. Открыть карточку товара.
2. Проверить основные элементы страницы.

Проверяемые элементы:
Название товара
Цена
Фотографии
Характеристики
Рейтинг
Отзывы
Информация о доставке

Ожидаемый результат:
Все данные отображаются корректно.

Статус:
Pass
