Test Report — Marketplace Web Application


Проект:
Ozon QA Testing Project


Описание:

В рамках учебного проекта было проведено ручное тестирование веб-приложения маркетплейса.

Цель тестирования:

Проверка основных пользовательских сценариев, выявление возможных дефектов и подготовка тестовой документации.


Объект тестирования:

Веб-приложение маркетплейса.


Окружение:

Браузер:
Яндекс Браузер

Операционная система:
Windows 11

Тип устройства:
Персональный компьютер



Выполненные виды тестирования:

Smoke testing

Проверка основных функций приложения после внесения изменений.


Functional testing

Проверка соответствия функциональности требованиям и пользовательским сценариям.


Regression testing

Проверка ранее работающего функционала после изменений.


UI testing

Проверка отображения элементов интерфейса.
